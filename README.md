# Build Jottr: A Minimal Note Taking App

### Project Description

You are going to build Jottr, a clean and simple app where users can write down notes and save them. You will start by setting up a database table to hold the text. Then, you will write custom Python functions to fetch those notes and display them on an HTML page. After that, you will build raw HTML forms to let users type in new ideas and save them directly to the database. Finally, you will wire up a delete button so users can clean up their workspace. You will write everything using raw function based views so you understand the exact flow of data from the database to the screen.
